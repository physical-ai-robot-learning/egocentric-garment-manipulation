# Status 2026-11-07: flattening with p_grasp on the robot

Follows [status_2026-11-05.md](status_2026-11-05.md) §5. No robot result in this document is counted: no flattening
policy has a success rate.

## 1. FLAT-PGRASP, offline (5–7 November)

- Data: the flattening data of 3, 4 and 5 November, train 301 demonstrations (534657 frames), val 46, test 45; the
  masked jaw slots of the state carry p_grasp of the left and right hand (`PGRASP=grasp-v2-W0.4`).
- Time-stretch comparison set up on 5 November: the same recipe at 0.3× (rented GPUs) and at 1.0× (cluster).
- 0.3×, `val_score_mm` (defined in [status_2026-11-02.md](status_2026-11-02.md)), val / test: 75.88 / 76.08 after
  epoch 1, 48.89 / 49.05 after epoch 14, best 46.04 / 46.61 at epoch 53; 46.36 / 46.76 at epoch 80. Not comparable with
  FLAT250 (different held-out sets) or with the 1.0× run (different time base).

## 2. Deploy (6 November)

- p_grasp on the robot: the deploy can run the same frozen classifier on the robot wrist cameras, but on the robot's
  closed, empty jaws it gives P(held) 0.97 (left) / 0.94 (right): the robot jaw looks larger and glossier than the HandUMI
  jaw. Default source is therefore the jaw state (P(held) = 1 while the jaw is closed, 0 while open, same window rule)
  until a robot-domain classifier exists.
- Deploy launchers on the robot computer now run the maintained `laundry_deploy` code; offline evaluation of one
  checkpoint gave the same output as the earlier code.

## 3. Robot runs (6–7 November)

- 6 November: the user judged the 0.3× policy to roll out better than the 1.0× one on the robot (runs not counted).
- 7 November: 27 policy runs with 0.3× FLAT-PGRASP checkpoints (epochs 53, 76, 77, 80, 81; one run with a 1.0×
  checkpoint), 14–174 s each, no safety-violation cycles. Typical behaviour: both jaws take an edge of the crumpled
  shirt, spread it between the arms and hold it; later the shirt bunches up again. No run laid the shirt flat on the
  table. Clearest run: 165051 (epoch 77), [media/flatten_policy_rollout_20261107_165051.gif](../media/flatten_policy_rollout_20261107_165051.gif).
- Runs were not counted or scored; this is an interim progress report.
