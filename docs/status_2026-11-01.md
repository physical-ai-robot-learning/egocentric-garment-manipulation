# Status 2026-11-01 (status note of 20:00 KST, updated 20:47): pinching feasibility test

Facts copied from the working status note of 1 November 2026 (kept outside this repository), so that the technical
report can cite them from a file in the repository. Nothing here is a robot result: **no robot trial of the pinching
policy has been run yet.** Names in `code font` are dataset / run names on the original machines.

## Goal

A first feasibility test of egocentric (HandUMI) demonstrations → reBot: **pinch ONE sleeve with the LEFT hand.**
The right arm is idle in all data (its jaw stays closed); the policy is deployed with the left arm only.

## Data

All sets are 0.5× time-stretched ("S05"), labelled with the **Cg** pose variant (CoTracker3 + marker anchors + constant
bias, IMU only inside tracking gaps), jaw label from the servo encoder, quality gate GOLD + SILVER, all used for training.

## Test sets (never trained on)

* **P20** = P10 (10-30 take 150454, 10 demos) + T10 (11-01 take 153036: 10 demos, 9 GOLD / 1 REJECT; the 9 GOLD are used)
  → **19 episodes, 6207 frames**, arm + gripper.
* Baseline: the E1000 DiT checkpoint at step 227795 (53 demos, A′ labels) scores **19.89 mm** `val_score_mm` on P20 with
  Cg labels (19.13 mm on the A′ version of P20). `val_score_mm` is defined in
  [`src/garment_pipeline/eval_deploy/tagrig_offline_eval.py`](../src/garment_pipeline/eval_deploy/tagrig_offline_eval.py):
  mean left/right translation deviation (mm) at k = 16 and k = 32.
* **Reject set:** every 11-01 demo the gate REJECTed, used for **gripper timing only** (the servo jaw labels are valid,
  the arm labels are not).

## Training

* E1000 (fine-tuned on the 53-demo 10-30 set, A′ labels, 0.5×) was stopped at step 227795 (about 725 epochs); its P10
  score had plateaued at 17.1–17.7 mm since about 150 epochs.
* Queued on 1 November, not yet started at 20:47 (scheduled to start automatically at about 21:00; about 5–6 days): DiT
  fine-tune **from the E1000 227795 weights** on the 200-demo Cg set (`umi_CG_S05_gs200_train`), new optimizer and cosine schedule over 500 epochs (a fine-tune, not a resume), a
  checkpoint every 25 epochs, gradient clipping off, jaw BCE head, batch 64 = 16 × gradient accumulation 4, RTX 4090 via Ray.
* New train-time image augmentation (`aug_image` in `src/garment_pipeline/training/tagrig_common.py`): global camera
  ±4.5 % / 2°, wrist cameras ±8 % / 5° / 5 % zoom, brightness / contrast ±15 %, colour channel ±5 %.
* Every checkpoint is evaluated on P20 (Cg) and on the reject set (gripper), and archived to the SSD.

## Robot and deploy changes on 1 November

* **Height calibration** (`src/garment_pipeline/eval_deploy/height_calib.py`): per-arm table plane from jaw-tip touches,
  robot FK vs. label frame. Left plane tilt 4.9° (+0 … −18 mm), right 2.6° (+13 … +3 mm). A UI checkbox adds dz(xy) to
  every committed row; the table stop uses the measured plane. Start-pose xy shift from touches on tags 400 / 401:
  left (+11, +14) mm, right (−3, +2) mm. A pivot fit of the TCP / joint offsets was rejected (the jaw tip is an edge; the
  fit was unstable); the kinematic configs are unchanged.
* **Fixed camera moved** since 10-26 (5–13 px, 0.5–1°); re-aimed to the 10-30 view (`cam_align.py`), residual about 5 px /
  0.4°.
* **Soft stop:** Space or the soft-stop button brakes on the current command without latching an E-stop; the hard E-stop
  button stays; safety stops still E-stop. READY unparks parked arms first and names an arm that refuses writes.
* Speed: UI maximum 2 (the S05 / S03 data is slowed); a speed above 1 caps the DiT commit at 32 / speed steps.
* **Left wrist connector** (j5 / j6 / gripper) dropped out twice; re-seated, bridge restarted with the same settings.
  During UMI recording the robot boards are unplugged.

failures; `solve2.py` can resume a re-sharded run; bad start seeds must be checked (the left seed of test take 153036
